Los símbolos que vas a ver

Depende de

Lo que tiene que existir antes de que este proceso funcione. Es la causa número uno de «no me deja»: casi nunca es un fallo, casi siempre es un paso previo que no se dio.

Lo que hace el sistema solo

Lo que se escribe sin que nadie lo teclee: la póliza contable, el movimiento de inventario, el saldo del banco, el costo del producto. Saber esto es la diferencia entre operar el sistema y pelearse con él.

Ojo

El error que comete todo el mundo, y cómo se ve cuando ocurre.

Ejercicio

Qué hacer en el ambiente de prácticas para fijar el capítulo. Si estás dando el curso, reserva tiempo para esto: leer el flujo no enseña el flujo.

Una advertencia sobre las pantallas

Todas las capturas de este manual son del sistema real, no maquetas. Los datos que se ven son de un ambiente de pruebas, así que los importes y los nombres no significan nada: lo que importa es dónde está cada cosa y qué botones hay.

Y algo que conviene entender desde la primera página: lo que tú ves en el sistema depende de tu rol. Si una pantalla de este manual no te aparece, no está rota — es que tu perfil no la incluye. El capítulo 0.6 explica cómo está repartido.
